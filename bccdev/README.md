# Project for BCC Developer (Windows PC)

**Borland C++ Compiler 5.5** is expected. You must edit the Include Path in "**Project Settings->Resources**" to match your environment. This compiler is quite old, supports Windows XP and older, and supports 32-bit applications only.

製作者はコンパイラとして **Borland C++ Compiler 5.5** を使用しています。また、**プロジェクト設定->リソース**のインクルードパスを環境に合わせて書き換える必要があります。このコンパイラは超古いので Windows XP にも対応する他、32-bit プログラム専用です。
