# Project for eMbedded Visual C++ 4.0 (Windows CE)

First, install **eMbedded Visual C++ 4.0** by following [HPC:Factor](https://www.hpcfactor.com/developer/) or similar resources. The release was created using Standard SDK for Windows CE .NET 4.0. While Windows 2000 and XP are the supported environments, it can also run on Windows 11 by using compatibility mode.

まず **eMbedded Visual C++ 4.0** を [Brain Wiki](https://brain.fandom.com/ja/wiki/Microsoft_eMbedded_Visual_C%2B%2B_4.0) などを参考にインストールしてください。リリースは Standard SDK for Windows CE .NET 4.0 で作成しています。Windows 2000 と XP がサポート環境ですが、互換モードを使えば Windows 11 でも動作します。
