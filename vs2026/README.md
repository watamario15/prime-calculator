# Project for Visual Studio 2026 (Windows PC)

This project uses **v145 C++ build tool** for Win32/x64 with **ARM64** support enabled. You must install these build tools first. If you have not installed them yet, Visual Studio will prompt you to install. You can still build for x64 and Win32 without ARM64 build tools.

**v145 C++ ビルドツール**を使用し、かつ **ARM64** を有効化しています。これらは別途インストールが必要で、なければプロジェクトを開いたときに求められるので、「不足しているプラグインのインストール」のような旨の項目をクリックし、インストールしてください。ARM64 用のビルドツールがなくても x64, Win32 版のビルドは可能です。
